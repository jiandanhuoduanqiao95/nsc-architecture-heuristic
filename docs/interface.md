# ctxnsc public interface (for roles B and C)

Everything below is importable from the repository root:

```python
from ctxnsc import (
    score_config,        # (config, alpha=0.0) -> float
    scores_for_alphas,   # (config_or_spec, alphas) -> {alpha: float}
    breakdown_config,    # (config, alpha) -> Breakdown
    score_with_ratios,   # (config, alpha, ratios) -> float   # M3 primitive
    position_ratios,     # (length) -> [float]                 # M3 weights
    original_nsc,        # (config) -> float                   # M1, re-exported
)
```

## Semantics and exceptions

| Function | Returns | Raises |
|---|---|---|
| `score_config(config, alpha)` | `S(alpha)` = Σ_l [A_l + F_l/(1+α·c_l)], `c_l = C_<l/S0` (strict prefix, conventions C1/C2) | `ValueError` for `alpha < 0` or non-finite `alpha`; `ValueError`/`KeyError` for malformed configs (via `nsc.layers`, and `weight_init_std` must be present and equal `0.02`) |
| `scores_for_alphas(target, alphas)` | dict alpha → score; terms/ratios computed once (≈5× faster than repeated `score_config`) | same as `score_config`; `target` may be a config dict or an `ArchitectureSpec` |
| `breakdown_config(config, alpha)` | `Breakdown` with per-layer `BreakdownItem(layer, attn, ffn, ratio, factor, contribution)` plus `s0, total, sum_attn, first_ffn` | same as `score_config` |
| `score_with_ratios(config, alpha, ratios)` | `S(alpha)` with caller-supplied per-layer ratios | same; `len(ratios)` must equal `n_layer` |
| `position_ratios(length)` | `[(i+1)/length]` — same weights as `nsc.position_example` | `ValueError` for `length < 1` |
| `original_nsc(config)` | the starter baseline (re-export; do not reimplement) | starter's `ValueError`s |

Guarantees:

- **No I/O, no labels, no global state.** Nothing in `ctxnsc/` opens a file,
  reads an environment variable, or consults config IDs (CH14 enforces this
  with an AST scan plus a runtime guard).
- **`alpha = 0` is exact**: `score_config(config, 0.0) == nsc.original_nsc(config)`
  bit-for-bit on all 200 archive configs (CH05). There is no special-case
  branch — it falls out of `1/(1+0·c) == 1` and `math.fsum`.
- **Starter grouping preserved**: per-layer `attn + ffn` is bit-identical to
  `nsc.layer_capacities(config)[l]` (CH04, elementwise, 200/200).
- Synthetic configs (toy pairs, probes) must carry `"weight_init_std": 0.02`;
  the adapter refuses to guess.

## M3 (position-only control) — 3-line wiring

Role B must NOT reimplement the discount. Use the primitive with the same
grid `{0, 0.25, 0.5, 1, 2}`, the same selection rule and the same tie-break
as M2:

```python
from ctxnsc import score_with_ratios, position_ratios

beta = 0.5                                   # from tools/select_alpha.py --method position
m3 = score_with_ratios(config, beta, position_ratios(config["n_layer"]))
```

`position_ratios(L)[i] == (i+1)/L`, matching `nsc.position_example`'s
weighting, so M3 isolates "layer index" from M2's "accumulated capacity".

Ready-made M3 student modules (generated by `tools/make_position_variants.py`,
verified by `--verify`), one per grid value — each is exactly:

```python
from nsc import original_nsc
from ctxnsc import score_with_ratios, position_ratios
BETA = 0.5                                   # file variants/m3_beta_0.50.py
def score(config): return score_with_ratios(config, BETA, position_ratios(config["n_layer"]))
def ablation(config): return original_nsc(config)
```

**B's β grid runs these 5 modules through the official harness**, exactly
like the α grid: `python3 evaluate.py --split development --student
variants/m3_beta_<b>.py --output results/dev_grid/m3_beta_<b>.json` for
`<b>` ∈ {0.00, 0.25, 0.50, 1.00, 2.00}; β* itself is chosen with the frozen
C4 rule by `python3 tools/select_alpha.py --method position --grid 0,0.25,0.5,1,2`.
Note M3 discounts every layer including the first ((i+1)/L > 0), so
`m3_beta_0.00` is the only variant equal to `original_nsc`.

## Tuning, C3 and selection tooling (who runs what)

- **B** runs the grids: `python3 tools/select_alpha.py --method cumulative --grid 0,0.25,0.5,1,2`
  (and `--method position` for M3). A only ever runs `--self-test`. The rule
  is frozen: canonical 12 significant digits → average-rank Spearman ρ vs
  negative dev PPL → max ρ → tie at 12 digits picks the SMALLER α, recorded
  in `tie_break_used`.
- **B** uses `python3 tools/normalization_probe.py` (C3, label-free) and
  `python3 tools/selection_ext.py` / `select_trials_ext(..., repeats=1000)`
  for the six-method × 1,000-trial selection experiment (same pools, same
  seed scheme `202627 + budget + k`, same shuffle-then-stable-sort).
- **α's single source** is `student_score.ALPHA`. For the grid use
  `--student variants/dev_alpha_<a>.py` (generated by `tools/make_variants.py`);
  never edit `evaluate.py`'s `REPEATS`.
- **`ablation(config)` always returns `original_nsc(config)`**, independent of
  ALPHA — that is the zero-strength ablation the harness expects.

## Selection export contract (B → `tools/selection_failures.py`)

B's six-method evaluator must export **`results/selection_1000.json`** in
this shape (one entry per method × cap × k; same pools for every method):

```json
{
  "split": "development",
  "trials": 1000,
  "entries": [
    {"method": "original_nsc", "cap": 10000000, "k": 1,
     "pool": ["config_id", "..."], "chosen": ["config_id", "..."],
     "chosen_ppl": [37.6], "best_ppl": 37.6, "oracle_ppl": 37.6, "regret": 0.0}
  ]
}
```

Required, per entry:

| field | meaning (checked by the tool) |
|---|---|
| `method` | canonical name — `original_nsc`, `ablation`, `position_example`, `reported_parameters`, `reference_flops`, `m2_alpha_<a>`, `m3_beta_<b>` — or any name with scores supplied in the optional top-level `scores` map; `random` entries are skipped |
| `cap`, `k` | positive integers (caps 10/20/30/50M, k ∈ {1, 3}) |
| `pool` | config ids with `resources.total <= cap` within the split, i.e. exactly the harness pool (any other set is rejected) |
| `chosen` | the **representative** choice = trial 1 of the harness tie-handling: `tools.selection_ext.representative_choice(pool, canonical_scores, k, seed=202627+cap+k)` (shuffle, then stable sort by score, take k) |
| `chosen_ppl` | the split's labels for `chosen`, same order |
| `best_ppl` | `min(chosen_ppl)` |
| `oracle_ppl` | lowest PPL in `pool` |
| `regret` | `best_ppl - oracle_ppl` |

Optional: per-entry `mean_best_ppl` / `mean_regret` / `sd_best_ppl` from
`select_trials_ext(..., repeats=1000)` (the tool notes entries whose 1,000-trial
mean differs from the representative — a sign of score ties) and `seed`;
top-level `scores: {method: {config_id: score}}` for methods without a
canonical name. Scores are compared after `evaluate.canonical`.

```sh
python3 tools/selection_failures.py --selection results/selection_1000.json \
    --split development --out-csv results/selection_failures.csv \
    --out-md docs/selection_failures.md
```

Output: `results/selection_failures.csv` (13 columns: `method, cap, k,
chosen_ids, chosen_ppl, best_id, best_ppl, gap, reason_tags,
score_rank_of_best, size_ratio_chosen_vs_best, depth_delta, width_delta`; one
row per failure, where `best_*` is the pool optimum and `gap = best PPL among
chosen - best_ppl`) and `docs/selection_failures.md` (failure table, tag
legend, ≥3 candidate cases for the report). `--split final` is refused unless
`--allow-final` is also given (B, after the freeze tag). Format preview from
the synthetic fixture: `docs/examples/selection_failures_example.{csv,md}`.

## Copy-paste example

```python
import json
from ctxnsc import score_config, scores_for_alphas, original_nsc

configs = json.load(open("data/architectures.json"))
for key in ("config_0_j0", "config_11_j2", "config_12_j5"):
    cfg = configs[key]
    scores = scores_for_alphas(cfg, (0.0, 0.5, 2.0))
    print(f"{key}: S0={scores[0.0]:.6f} (== original_nsc: "
          f"{scores[0.0] == original_nsc(cfg)}), S(0.5)={scores[0.5]:.6f}, "
          f"S(2)={scores[2.0]:.6f}")
```

Run from the repository root; expected output (measured):

```
config_0_j0: S0=589.868165 (== original_nsc: True), S(0.5)=517.201199, S(2)=411.595127
config_11_j2: S0=1584.388338 (== original_nsc: True), S(0.5)=1492.074446, S(2)=1345.572469
config_12_j5: S0=13046.776625 (== original_nsc: True), S(0.5)=11745.487531, S(2)=9936.668188
```
